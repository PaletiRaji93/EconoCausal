# EconoCausal

Dynamic Pricing via Double Machine Learning

## Objective

Estimate how marketing discounts influence customer purchase
outcomes, analyze heterogeneous treatment effects, and develop
budget-constrained discount recommendations.

## Current progress

- [x] Repository initialization
- [ ] Synthetic retail dataset
- [ ] Dataset validation and exploratory analysis
- [ ] Causal graph and assumptions
- [ ] Propensity score analysis
- [ ] Double Machine Learning
- [ ] Causal refutation and uplift evaluation
- [ ] Budget optimization
- [ ] FastAPI backend and SQLite persistence
- [ ] React and Plotly dashboard
- [ ] Experiment tracking and data drift monitoring

## Initial setup

Create a Python virtual environment and install the dependencies
listed in requirements.txt.

## Dataset

The initial development dataset is synthetic. It must not be
presented as real customer or business data.

## Limitations

Causal estimates depend on treatment assignment, observed
confounders, overlap, model assumptions and data quality.
